# Управление (Control)

**Файл:** `ControlTools.kt`

---

## 1. `clipboard_read` — Прочитать буфер обмена

**Что делает:** Возвращает содержимое буфера обмена (последний скопированный текст).

**Параметры:** Нет

**Ограничения:** Нет

**Пример:** "Что в буфере?" → покажет последний скопированный текст

---

## 2. `clipboard_write` — Скопировать в буфер

**Что делает:** Копирует текст в буфер обмена (как Ctrl+C).

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| text | string | ✅ | Текст для копирования |

**Ограничения:** Нет

**Пример:** "Скопируй это" → скопирует текст в буфер

---

## 3. `volume_control` — Управление громкостью

**Что делает:** Устанавливает громкость для медиа, звонка, уведомлений или системных звуков.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| stream | string | ✅ | Тип: media, ringtone, notification, system |
| level | string | ✅ | Уровень: 0-100, mute, max |

**Ограничения:** Нет

**Пример:** "Сделай громче" → увеличит медиа громкость

---

## 4. `brightness` — Управление яркостью

**Что делает:** Устанавливает яркость экрана или включает авторежим.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| level | string | ✅ | Яркость: 0-100 или auto |

**Ограничения:** Нужно разрешение WRITE_SETTINGS

**Пример:** "Сделай ярче" → увеличит яркость экрана

---

## 5. `flashlight` — Фонарик

**Что делает:** Включает или выключает вспышку (фонарик) на задней панели.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| state | string | ✅ | on (включить) или off (выключить) |

**Ограничения:** Нет

**Пример:** "Включи фонарик" → включит вспышку
