# Коммуникации

**Файл:** `CommunicationTools.kt`  
**Требует:** Разрешения SEND_SMS, CALL_PHONE, READ_CONTACTS, READ_SMS

---

## 1. `send_sms` — Отправить SMS

**Что делает:** Отправляет SMS-сообщение на указанный номер.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| phone | string | ✅ | Номер телефона (+380501234567) |
| message | string | ✅ | Текст сообщения |

**Ограничения:** Нужно разрешение SEND_SMS

**Пример:** "Отправь маме смс: я буду через час" → отправит SMS

---

## 2. `make_call` — Позвонить

**Что делает:** Совершает телефонный звонок. Если нет разрешения, открывает набор номера.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| phone | string | ✅ | Номер телефона для звонка |

**Ограничения:** Нужно разрешение CALL_PHONE для прямого звонка

**Пример:** "Позвони маме" → найдёт номер в контактах и позвонит

---

## 3. `search_contacts` — Найти контакт

**Что делает:** Ищет контакт в телефонной книге по имени.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| query | string | ✅ | Имя для поиска ("Мама", "Иван", "Ева Директор") |

**Ограничения:** Нужно разрешение READ_CONTACTS

**Пример:** "Найди контакт Иван" → покажет номер Ивана

---

## 4. `read_sms` — Прочитать SMS

**Что делает:** Возвращает список последних входящих SMS с номером отправителя, текстом и датой.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| count | number | ❌ | Количество SMS для чтения (по умолчанию 10) |

**Ограничения:** Нужно разрешение READ_SMS

**Пример:** "Прочитай последние смс" → покажет 10 последних сообщений

---

## 5. `search_sms` — Поиск SMS

**Что делает:** Ищет SMS по тексту, номеру или дате.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| query | string | ✅ | Текст для поиска (номер, имя, или слово) |
| limit | number | ❌ | Макс. результатов (по умолчанию 20) |

**Ограничения:** Нужно разрешение READ_SMS

**Пример:** "Найди смс от Оли" → покажет все SMS от Оли

---

## 6. `launch_url` — Открыть ссылку

**Что делает:** Открывает URL в браузере.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| url | string | ✅ | URL для открытия (https://google.com) |

**Ограничения:** Нет

**Пример:** "Открой гугл" → откроет https://google.com в браузере

---

## 7. `share_text` — Поделиться текстом

**Что делает:** Открывает диалог "Поделиться" для отправки текста через любое приложение.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| text | string | ✅ | Текст для отправки |
| subject | string | ❌ | Тема/заголовок |

**Ограничения:** Нет

**Пример:** "Поделись этим текстом" → откроет выбор приложения для отправки
