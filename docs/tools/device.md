# Устройство (Device)

**Файл:** `DeviceTools.kt`

---

## 1. `battery_info` — Информация о батарее

**Что делает:** Показывает текущий заряд батареи в процентах, статус и статус зарядки.

**Параметры:** Нет

**Ограничения:** Нет

**Возвращает:**
```
Battery: 75%
Status: GOOD
Charging: No
```

**Пример:** "Сколько заряда?" → покажет процент заряда

---

## 2. `device_info` — Информация об устройстве

**Что делает:** Показывает модель устройства, версию Android, хранилище и разрешение экрана.

**Параметры:** Нет

**Ограничения:** Нет

**Возвращает:**
```
Device: Samsung Galaxy S21
Android: 14 (API 34)
Storage: 82.5 GB used / 128 GB total (45.5 GB free)
Display: 1080x2400
```

**Пример:** "Какой у меня телефон?" → покажет модель и характеристики

---

## 3. `storage_info` — Информация о хранилище

**Что делает:** Показывает детальный отчёт о хранилище: общий объём, использовано, свободно.

**Параметры:** Нет

**Ограничения:** Нет

**Возвращает:**
```
Total: 128 GB
Used: 82.5 GB (64%)
Free: 45.5 GB
```

**Пример:** "Сколько памяти?" → покажет использование хранилища
