# Медиа

**Файл:** `MediaTools.kt`

---

## 1. `media_control` — Управление воспроизведением

**Что делает:** Управляет воспроизведением музыки через медиа-клавиши.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| action | string | ✅ | Действие |

**Действия:**
| Действие | Что делает |
|----------|------------|
| play | Воспроизведение |
| pause | Пауза |
| next | Следующий трек |
| previous | Предыдущий трек |
| volume_up | Громкость + |
| volume_down | Громкость - |

**Ограничения:** Работает только с активным медиа-плеером

**Пример:** "Следующая песня" → переключит на следующий трек

---

## 2. `play_store_search` — Поиск в Google Play

**Что делает:** Ищет приложения в Google Play Store через DuckDuckGo.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| query | string | ✅ | Поисковый запрос |

**Ограничения:** Нужен интернет

**Пример:** "Найди приложение для заметок" → покажет результаты из Google Play

---

## 3. `open_play_store` — Открыть в Google Play

**Что делает:** Открывает страницу приложения в Google Play для установки.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| package_name | string | ✅ | Package name приложения |

**Ограничения:** Нужно знать package name

**Пример:** "Установи это приложение" → откроет страницу в Google Play
