# Приложения

**Файл:** `AppAndInfoTools.kt`

---

## 1. `open_app` — Запустить приложение

**Что делает:** Запускает приложение по названию. Использует **гибридный подход**:
1. **Локальный поиск** (мгновенно): точное совпадение → словарь синонимов → подстрока → Левенштейн
2. **LLM fallback** (1-2 сек): если локально не нашёл, спрашивает OpenAI

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| name | string | ✅ | Название приложения ("заметки", "YouTube", "телега") |

**Словарь синонимов (30+ записей):**
| Запрос | Ищет |
|--------|------|
| заметки, записи | Notes, Notepad, Keep |
| телега, телеграм | Telegram |
| ютуб, труба | YouTube |
| хром, браузер | Chrome |
| камера, фотик | Camera |
| галерея, фото | Gallery, Photos |
| музыка, плеер | Music, Spotify |
| карты, навигатор | Maps, Waze |
| почта, имаил | Gmail, Mail |

**Ограничения:** Нет

**Пример:** "Открой заметки" → найдёт Google Keep или Notepad и запустит

---

## 2. `self_awareness` — Управление видимостью агента

**Что делает:** Контролирует видимость агента на экране.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| action | string | ✅ | show, hide, toggle |

**Ограничения:** Нет

**Пример:** "Спрячься" → скроет панель агента

---

## 3. `agent_status` — Статус агента

**Что делает:** Возвращает текущий статус агента (видим/скрыт, версия).

**Параметры:** Нет

**Ограничения:** Нет

**Пример:** "Какой у тебя статус?" → покажет информацию о себе
