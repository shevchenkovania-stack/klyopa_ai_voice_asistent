# Рисование

**Файл:** `DrawImageTool.kt`

---

## 1. `draw_image` — Нарисовать изображение

**Что делает:** Рисует фигуры и картинки на цветном фоне, сохраняет как PNG в галерею.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| shape | string | ✅ | Что нарисовать |
| color | string | ❌ | Цвет фигуры |
| bg_color | string | ❌ | Цвет фона (по умолчанию black) |
| shape2 | string | ❌ | Вторая фигура другим цветом |
| color2 | string | ❌ | Цвет второй фигуры |
| text | string | ❌ | Текст для shape='text' |
| filename | string | ❌ | Имя файла |
| save_path | string | ❌ | Папка для сохранения |
| size | number | ❌ | Размер в пикселях (по умолчанию 512) |

**Простые фигуры:**
- `circle` — круг
- `rectangle` — прямоугольник
- `line` — линия
- `text` — текст
- `heart` — сердечко
- `star` — звезда

**Картинки (составные):**
- `sun` — солнышко (круг с лучами)
- `person` — человечек (голова, тело, руки, ноги)
- `house` — домик (стены, крыша, дверь, окно)
- `tree` — дерево (ствол + крона из кругов)
- `flower` — цветок (лепестки + стебель)
- `smiley` — смайлик (лицо с глазами и улыбкой)
- `snowman` — снеговик (3 шара, глаза, нос-морковка)

**Цвета:** red, blue, green, yellow, white, black, orange, purple, pink, cyan, brown, gray  
**Русские цвета:** красный, синий, зелёный, жёлтый, белый, чёрный, оранжевый, фиолетовый, розовый, голубой, коричневый, серый

**Ограничения:** Нет

**Примеры:**
- "Нарисуй солнышко" → жёлтое солнце на голубом фоне
- "Нарисуй розовое сердечко на белом" → розовое сердце на белом фоне
- "Нарисуй человечка" → простой человечек
