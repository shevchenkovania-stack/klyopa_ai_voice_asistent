# Камера

**Файл:** `CameraTools.kt`  
**Требует:** Разрешение CAMERA

---

## 1. `take_selfie` — Сделать селфи

**Что делает:** Открывает **фронтальную** камеру, делает снимок без превью, сохраняет JPEG в галерею.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| timer | number | ❌ | Таймер в секундах перед съёмкой (по умолчанию 3) |
| save_path | string | ❌ | Папка для сохранения (по умолчанию /sdcard/Pictures/) |

**Ограничения:**
- Нужно разрешение CAMERA
- Камера может быть занята другим приложением

**Пример:** "Сделай селфи" → откроет фронталку, обратный отсчёт 3 сек, фото в галерею

---

## 2. `take_photo` — Сделать фото

**Что делает:** Открывает **основную (заднюю)** камеру, делает снимок без превью, сохраняет JPEG в галерею.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| timer | number | ❌ | Таймер в секундах перед съёмкой (по умолчанию 0) |
| save_path | string | ❌ | Папка для сохранения (по умолчанию /sdcard/Pictures/) |

**Ограничения:**
- Нужно разрешение CAMERA
- Камера может быть занята другим приложением

**Пример:** "Сними на камеру" → откроет заднюю камеру, сделает фото
