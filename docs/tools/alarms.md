# Будильники и таймеры

**Файл:** `AlarmTimerTools.kt`

---

## 1. `set_alarm` — Установить будильник

**Что делает:** Устанавливает будильник на указанное время. Открывает системное приложение Часы.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| hour | integer | ✅ | Часы (0-23) |
| minute | integer | ✅ | Минуты (0-59) |
| label | string | ❌ | Название будильника |

**Ограничения:** Нет

**Пример:** "Разбуди меня в 7 утра" → установит будильник на 07:00

---

## 2. `cancel_alarm` — Отменить будильник

**Что делает:** Отменяет установленный будильник.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| alarm_id | integer | ❌ | ID будильника (если известен) |

**Ограничения:** Без ID отменит все будильники

**Пример:** "Отмени будильник" → откроет экран отмены будильников

---

## 3. `set_timer` — Установить таймер

**Что делает:** Устанавливает таймер обратного отсчёта. Таймер сработает в системном приложении Часы.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| seconds | integer | ✅ | Длительность в секундах |
| label | string | ❌ | Название таймера |

**Ограничения:** Нет

**Пример:** "Поставь таймер на 5 минут" → установит таймер на 300 секунд

---

## 4. `cancel_timer` — Отменить таймер

**Что делает:** Отменяет установленный таймер.

**Параметры:** Нет

**Ограничения:** Нет

**Пример:** "Останови таймер" → отменит активный таймер
