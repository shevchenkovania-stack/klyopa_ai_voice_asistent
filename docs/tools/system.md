# Система (System)

**Файлы:** `SystemControlTool.kt`, `SystemTools.kt`

---

## 1. `system_control` — Системные настройки

**Что делает:** Управляет настройками телефона: WiFi, Bluetooth, фонарик, громкость, яркость.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| action | string | ✅ | Действие |
| value | number | ❌ | Значение для set_volume (0-100) или set_brightness (0-255) |

**Действия:**
| Действие | Что делает | Ограничения |
|----------|------------|-------------|
| toggle_wifi | Переключить WiFi | Android 10+: открывает настройки |
| toggle_bluetooth | Переключить Bluetooth | Android 12+: открывает настройки |
| toggle_flashlight | Включить/выключить фонарик | Нет |
| set_volume | Установить громкость (0-100) | Нет |
| set_brightness | Установить яркость (0-255) | Нужно WRITE_SETTINGS |

**Ограничения WiFi/Bluetooth:**
- **Android 10+** не позволяет переключать WiFi программно → открывается панель настроек
- **Android 12+** не позволяет переключать Bluetooth программно → открываются настройки Bluetooth
- Пользователь должен вручную включить/выключить в открывшихся настройках

**Пример:** "Включи WiFi" → откроет настройки WiFi (на Android 10+)

## 2. `list_apps` — Список приложений

**Что делает:** Показывает список установленных приложений.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| filter | string | ❌ | Фильтр по имени |
| limit | number | ❌ | Макс. приложений (по умолчанию 20) |

**Ограничения:** Нет

**Пример:** "Какие приложения установлены?" → покажет список

---

## 3. `app_info` — Информация о приложении

**Что делает:** Показывает информацию об установленном приложении.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| app_name | string | ✅ | Имя или package name приложения |

**Ограничения:** Нет

**Пример:** "Что за приложение Chrome?" → покажет версию, package name, system app

---

## 4. `network_info` — Информация о сети

**Что делает:** Показывает статус сетевого подключения.

**Параметры:** Нет

**Ограничения:** Нет

**Возвращает:**
```
Connected: Yes
Type: WiFi
Internet: Available
Metered: No (unlimited)
```

**Пример:** "Есть интернет?" → покажет статус подключения
