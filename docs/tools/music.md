# Музыка

**Файл:** `SearchLocalMusicTool.kt`

---

## 1. `search_local_music` — Поиск музыки на устройстве

**Что делает:** Ищет музыкальные файлы на устройстве по названию, исполнителю или альбому.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| query | string | ✅ | Поисковый запрос (название, исполнитель, альбом) |
| limit | number | ❌ | Макс. результатов (по умолчанию 10) |

**Ограничения:** 
- Ищет только в медиа-хранилище Android
- Не видит файлы в приватных папках

**Возвращает:**
```
Found 3 song(s) matching 'imagine':
1. Imagine
   Artist: John Lennon
   Album: Imagine
   Path: /sdcard/Music/imagine.mp3
...
```

**Пример:** "Найди песню Imagine" → покажет найденные треки с путями
