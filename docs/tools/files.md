# Файлы

**Файлы:** `FileTools.kt`, `WifiFileTools.kt`

---

## 1. `create_folder` — Создать папку

**Что делает:** Создаёт новую папку на устройстве.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| name | string | ✅ | Имя папки |
| parent | string | ❌ | Родительская папка (по умолчанию Documents) |

**Ограничения:** Нет

**Пример:** "Создай папку Работа" → создаст /Documents/Работа

---

## 2. `list_files` — Список файлов

**Что делает:** Показывает содержимое папки с размерами и типами.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| path | string | ✅ | Путь к папке |

**Ограничения:** Нет

**Пример:** "Что в папке Загрузки?" → покажет список файлов

---

## 3. `delete_file` — Удалить файл

**Что делает:** Удаляет файл или пустую папку.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| path | string | ✅ | Путь к файлу |

**Ограничения:** 
- Удаляет только пустые папки
- Не удаляет системные файлы

**Пример:** "Удали заметки.txt" → удалит файл

---

## 4. `write_file` — Записать в файл

**Что делает:** Записывает текст в файл. Создаёт файл если не существует.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| path | string | ✅ | Путь к файлу |
| content | string | ✅ | Текст для записи |
| append | boolean | ❌ | Если true — дописать в конец |

**Ограничения:** Нет

**Пример:** "Запиши это в файл" → создаст/допишет файл

---

## 5. `open_file` — Открыть файл

**Что делает:** Открывает файл в приложении по умолчанию.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| path | string | ✅ | Путь к файлу |

**Ограничения:** Нужно приложение для открытия файла

**Пример:** "Открой документ.pdf" → откроет в PDF-ридер

---

## 6. `file_info` — Информация о файле

**Что делает:** Показывает размер, тип, дату изменения файла.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| path | string | ✅ | Путь к файлу |

**Ограничения:** Нет

**Пример:** "Что за файл?" → покажет информацию

---

## 7. `create_file` — Создать файл

**Что делает:** Создаёт текстовый файл с содержимым.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| filename | string | ✅ | Имя файла |
| content | string | ✅ | Содержимое файла |
| folder | string | ❌ | Папка (по умолчанию Documents) |

**Ограничения:** Нет

**Пример:** "Создай файл заметки.txt" → создаст файл

---

## 8. `read_file` — Прочитать файл

**Что делает:** Читает содержимое текстового файла из /Documents/.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| filename | string | ✅ | Имя файла |

**Ограничения:** Ищет только в /sdcard/Documents/

**Пример:** "Прочитай заметки.txt" → покажет содержимое
