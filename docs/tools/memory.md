# Память (Memory)

**Файл:** `MemoryTools.kt`

---

## 1. `remember_fact` — Запомнить факт

**Что делает:** Запоминает факт о пользователе в долгосрочную память. Агент сам решает что запоминать: имена, номера, предпочтения.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| fact | string | ✅ | Факт для запоминания |

**Ограничения:** Максимум 10 фактов в памяти

**Примеры:**
- "Запомни: мама — Елена" → сохранит факт
- "Запомни что я на ты" → сохранит предпочтение

---

## 2. `forget_fact` — Забыть факт

**Что делает:** Удаляет факт из долгосрочной памяти.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| fact | string | ✅ | Факт или его часть для удаления |

**Ограничения:** Нет

**Пример:** "Забудь про маму" → удалит факт о маме
