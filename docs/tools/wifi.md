## 1. `connect_wifi` — Подключиться к WiFi

**Что делает:** Подключается к WiFi сети по имени.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| ssid | string | ✅ | Имя WiFi сети |
| password | string | ❌ | Пароль (если сеть закрытая) |

**Ограничения:**
- **Android 10+**: Нельзя подключаться программно → открывает настройки WiFi
- Пользователь должен выбрать сеть вручную

**Поведение:**
| Android | Открытая сеть | Закрытая сеть |
|---------|---------------|---------------|
| < 10 | Подключается автоматически | Просит пароль |
| ≥ 10 | Открывает настройки WiFi | Открывает настройки WiFi |

**Пример:** "Подключи меня к WiFi Nessa" → откроет настройки WiFi для выбора сети
