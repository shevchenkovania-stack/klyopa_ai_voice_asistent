# Загрузка файлов

**Файл:** `DownloadFileTool.kt`

---

## 1. `download_file` — Скачать файл

**Что делает:** Скачивает файл по URL и сохраняет на устройство. Поддерживает MP3, изображения, PDF и другие форматы.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| url | string | ✅ | Прямая ссылка на файл для скачивания |
| filename | string | ❌ | Имя файла (авто-определение из URL) |
| folder | string | ❌ | Папка: Downloads, Music, Documents, Pictures |

**Ограничения:**
- Нужна прямая ссылка (не страница с файлом)
- Может не работать с сайтами, требующими авторизацию

**Пример:** "Скачай песню по ссылке..." → скачает MP3 в папку Music
