# Инструменты доступности (Accessibility)

**Файл:** `AccessibilityTools.kt`  
**Требует:** AccessibilityService включён в настройках телефона

---

## 1. `read_screen` — Прочитать экран

**Что делает:** Возвращает список всех элементов на экране с их типами и текстом. Это "глаза" агента.

**Параметры:** Нет

**Ограничения:** 
- Нужен включённый AccessibilityService
- Без сервиса вернёт ошибку

**Пример:** Клёпа скажет "Что на экране?" → прочитает все кнопки, тексты, поля

---

## 2. `click_element` — Нажать на элемент

**Что делает:** Нажимает на элемент по его тексту. Это "палец" агента.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| text | string | ✅ | Текст элемента (например "Отправить", "Настройки") |

**Ограничения:**
- Нужен AccessibilityService
- Ищет точное совпадение текста

**Пример:** "Нажми на Настройки" → найдёт кнопку "Настройки" и нажмёт

---

## 3. `type_text` — Ввести текст

**Что делает:** Вводит текст в активное поле ввода. Это "клавиатура" агента.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| text | string | ✅ | Текст для ввода |
| field_label | string | ❌ | Метка поля для точного позиционирования |

**Ограничения:**
- Нужен AccessibilityService
- Нужно активное поле ввода

**Пример:** "Введи привет" → напечатает "привет" в текущем текстовом поле

---

## 4. `navigate` — Системная навигация

**Что делает:** Выполняет системные действия навигации.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| action | string | ✅ | back, home, recents, notifications, quick_settings, power_dialog |

**Действия:**
| Действие | Что делает |
|----------|------------|
| back | Нажатие кнопки "Назад" |
| home | Возврат на главный экран |
| recents | Открыть недавние приложения |
| notifications | Открыть панель уведомлений |
| quick_settings | Открыть быстрые настройки |
| power_dialog | Открыть меню питания |

**Ограничения:** Нужен AccessibilityService

**Пример:** "Вернись назад" → нажмёт кнопку Back

---

## 5. `scroll` — Прокрутка экрана

**Что делает:** Прокручивает экран вверх или вниз.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| direction | string | ✅ | "up" или "down" |

**Ограничения:**
- Нужен AccessibilityService
- Работает только на прокручиваемых контейнерах

**Пример:** "Прокрути вниз" → пролистает экран вниз

---

## 6. `list_clickable` — Список кликабельных элементов

**Что делает:** Показывает все кликабельные элементы на экране с координатами.

**Параметры:** Нет

**Ограничения:** Нужен AccessibilityService

**Пример:** "Что можно нажать?" → покажет список кнопок с координатами
