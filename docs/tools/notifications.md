# Уведомления (Notifications)

**Файл:** `NotificationTools.kt`  
**Требует:** NotificationListener включён в настройках

---

## 1. `read_notifications` — Прочитать уведомления

**Что делает:** Читает все активные уведомления на телефоне. Показывает приложение, заголовок и текст каждого уведомления.

**Параметры:** Нет

**Ограничения:** 
- Нужен включённый NotificationListener
- Без сервиса вернёт пустой список

**Пример:** "Какие уведомления?" → покажет все активные уведомления

---

## 2. `dismiss_notification` — Убрать уведомление

**Что делает:** Закрывает/убирает уведомление по названию приложения.

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| app_name | string | ✅ | Название приложения (Telegram, WhatsApp) |

**Ограничения:** Нужен NotificationListener

**Пример:** "Убери уведомление от Телеграм" → закроет уведомление
