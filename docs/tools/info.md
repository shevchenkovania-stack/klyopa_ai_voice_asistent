# Информация

**Файлы:** `InfoTools.kt`, `GetCurrentTimeTool.kt`

---

## 1. `get_current_time` — Текущее время

**Что делает:** Возвращает текущую дату и время на устройстве.

**Параметры:** Нет

**Ограничения:** Нет

**Возвращает:** "Текущее время: среда, 3 июля 2024, 14:30"

**Пример:** "Который час?" → покажет текущее время

---

## 2. `get_weather` — Погода

**Что делает:** Узнаёт погоду в городе через wttr.in (бесплатно, без ключа).

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| city | string | ✅ | Название города |
| days | number | ❌ | Прогноз на сколько дней (0-3) |

**Ограничения:** Нужен интернет

**Возвращает:**
```
Погода в городе Москва:
Температура: 25°C (ощущается как 27°C)
Описание: ясно
Влажность: 45%
Ветер: 10 км/ч

Совет по одежде: Тепло. Лёгкая одежда, футболка.
```

**Пример:** "Какая погода в Москве?" → покажет погоду и совет по одежде

---

## 3. `get_currency_rate` — Курс валют

**Что делает:** Узнаёт курс валют через exchangerate-api.com (бесплатно).

**Параметры:**
| Параметр | Тип | Обяз. | Описание |
|----------|-----|-------|----------|
| from | string | ✅ | Код исходной валюты (USD, EUR, MDL) |
| to | string | ✅ | Код целевой валюты |
| amount | number | ❌ | Сумма для конвертации (по умолчанию 1) |

**Ограничения:** Нужен интернет

**Пример:** "Сколько долларов в 100 евро?" → покажет курс

---

## 4. `get_location` — Местоположение

**Что делает:** Определяет текущее местоположение пользователя (город) через GPS/Network.

**Параметры:** Нет

**Ограничения:** 
- Нужно разрешение на геолокацию
- Нужно включить GPS или сетевое определение

**Возвращает:**
```
Текущее местоположение: Кишинёв, Молдова
Полный адрес: ...
Координаты: 47.0105, 28.8638
```

**Пример:** "Где я?" → определит город
