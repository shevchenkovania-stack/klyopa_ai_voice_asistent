# Тест: Точечное рисование (Dot-Art)

## Цель
Проверить что `draw_image` корректно рисует из точек (dot) с координатами x,y.
Проверить что LLM генерирует правильный tool call с `elements` массивом.

## Критерии прохождения (Pass Criteria)

### 1. Инструмент (детерминированный тест)
| # | Критерий | Проверка |
|---|----------|----------|
| 1 | `draw_image` вызван с `elements` | `success == true` |
| 2 | Файл создан | `File("/sdcard/Pictures/drawing.png").exists()` |
| 3 | Валидный PNG | Размер файла > 100 байт |
| 4 | Правильные размеры | Bitmap width == size (512 по умолчанию) |
| 5 | Не пустой | Bitmap не полностью одного цвета (есть нарисованные точки) |

### 2. LLM (недетерминированный тест)
| # | Критерий | Проверка |
|---|----------|----------|
| 1 | LLM вызвал `draw_image` | Логи: `Вызов: draw_image` |
| 2 | Передал `elements` массив | `elements` не null и не пустой |
| 3 | Каждый элемент — точка | `shape == "dot"` |
| 4 | Каждый элемент имеет координаты | `x` и `y` присутствуют (0.0-1.0) |
| 5 | Минимум 10 точек | `elements.size >= 10` |

## Тестовые сценарии

### Сценарий 1: Простой цветок из точек
**Вход:** `elements` с 20+ точками, формирующими цветок
**Ожидание:** PNG создан, содержит разноцветные точки (лепестки + стебель)

### Сценарий 2: Сердце из точек
**Вход:** `elements` с 15+ красными точками в форме сердца
**Ожидание:** PNG создан, точки формируют узнаваемое сердце

### Сценарий 3: Смайлик из точек
**Вход:** `elements` с 25+ жёлтыми точками на чёрном фоне
**Ожидание:** PNG создан, точки формируют смайлик (круг + глаза + рот)

### Сценарий 4: Абстрактный паттерн
**Вход:** `elements` с 30+ точками случайных цветов и позиций
**Ожидание:** PNG создан, содержит множество разноцветных точек

### Сценарий 5: Голосовая команда (LLM тест)
**Вход:** "нарисуй цветочек из точек"
**Ожидание:** LLM генерирует elements с dot-фигурами, файл создан

## Автоматический тест (runDotArtTest)

Вызывается через MethodChannel: `runDotArtTest`

Проверяет сценарии 1-4 программно:
1. Генерирует тестовые элементы для каждого сценария
2. Вызывает `draw_image` с каждым набором
3. Проверяет критерии 1-5
4. Возвращает отчёт: PASS/FAIL для каждого сценария

## Как запустить
- На устройстве: Tool Tester → вкладка "Ядро" → кнопка "Тест: Рисование точками"
- Или голосом: "запусти тест рисования"
