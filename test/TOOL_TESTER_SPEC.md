# Спецификация тестов инструментов Клёпы

## Принцип

Каждый тест должен **наглядно демонстрировать результат** в реальном времени.
Не просто "выполнилось успешно", а **видимый/слышимый эффект**.

---

## Категории тестов

### 1. 🔊 Звук и аудио (слышимый эффект)
| Инструмент | Ожидаемый эффект |
|------------|------------------|
| `volume_control` | Ползунок громкости, реальное изменение громкости |
| `media_control` | Play/Pause/Next — музыка играет или останавливается |
| `system_control: set_volume` | Громкость меняется в реальном времени |

### 2. 💡 Визуальный эффект (видимый на экране)
| Инструмент | Ожидаемый эффект |
|------------|------------------|
| `system_control: toggle_flashlight` | Фонарик включается/выключается |
| `system_control: set_brightness` | Яркость экрана меняется |
| `system_control: toggle_wifi` | WiFi иконка меняется, статус обновляется |
| `system_control: toggle_bluetooth` | Bluetooth иконка меняется |

### 3. 📷 Камера (визуальный результат)
| Инструмент | Ожидаемый эффект |
|------------|------------------|
| `take_selfie` | Открывается камера, делается фото, показывается превью |
| `take_photo` | То же с основной камеры |

### 4. 📂 Файлы (видимый результат в файловой системе)

## Требования к UI тестов

### Для каждого инструмента:

1. **Иконка** — визуально отражает действие
2. **Название** — понятное, на русском
3. **Параметры** — интерактивные (слайдеры, тогглы, поля ввода)
4. **Результат** — отображается сразу после выполнения
5. **Время** — сколько выполнялось

### Интерактивные контролы:

| Тип параметра | UI контрол |
|---------------|------------|
| `boolean` (вкл/выкл) | Switch/Toggle |
| `number` (0-100) | Slider |
| `string` (текст) | TextField |
| `enum` (выбор) | Dropdown |
| `action` (действие) | Button |

## Примеры правильного теста

### ✅ Правильно: volume_control
```
[🔊 Громкость]
[=====●=====] 50%  [Применить]
→ Громкость установлена на 50%
```

### ❌ Неправильно: volume_control
```
volume_control → Success (150ms)
```

### ✅ Правильно: take_selfie
```
[📷 Селфи]
[Таймер: 3 сек ▼]
[Сделать фото]
→ [Превью фото]
```

### ❌ Неправильно: take_selfie
```
take_selfie → Success (2500ms)
```

## Запрещено

- ❌ Тесты без видимого эффекта
- ❌ Просто "Success" без деталей
- ❌ Тесты которые ломают устройство
- ❌ Тесты которые отправляют реальные SMS/звонки без подтверждения
